# TestMate Application Project

A desktop-first collaborative calendar platform built with React, Lucide icons, and Tailwind CSS. Specially customized for teachers to coordinate assessments, balance mental workload, and protect student cognitive schedules.

## Local Development Execution Instructions

Follow these steps to unpack and spin up the project locally:

1. **Unzip the project directory**:
   Extract all contents of this ZIP folder.

2. **Install project dependencies**:
   Open your terminal in the extracted directory and run:
   ```bash
   npm install
   ```

3. **Spin up local dev server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   The app will automatically launch at [http://localhost:3000](http://localhost:3000).
